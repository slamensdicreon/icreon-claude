## Reference: known Optimizely CMS (SaaS) pitfalls

Gathered from Optimizely's CMS (SaaS) documentation, the JavaScript SDK's documentation and its
2026 release notes while this playbook was written; no site has been built with it yet, so treat
every row as a thing to verify, not a guarantee. When your evidence says otherwise, trust the
evidence and say so in your result.

Working rules:

- A 2xx means the change was **executed**, not **verified**. Read the content type, the version or
  the Graph item back and compare it with what you intended before you report done.
- After a timeout or an unclear failure on a write, read back first: a create that timed out may
  have succeeded. Never retry a write before you know its state. Don't retry authorization, schema
  or scope failures at all.
- Content types, display templates, property groups and Graph are shared by every application on
  the instance. Create only keys that start with the project's prefix, and never change a type
  that lacks it.
- Publishing is immediate in the CMS, but Graph indexes afterwards. A route check that runs right
  after a publish can be stale: wait for the item to appear in Graph before you judge it.

| Symptom                                                                               | Likely cause                                                                                                      | What to do                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Calls to `/_cms/preview3/...` fail or are refused                                     | Preview3 was retired on 1 August 2026                                                                             | Use CMS REST API v1 on `https://api.cms.optimizely.com/v1/...` with a bearer token from `/oauth/token`. Status changes are no longer a field on create                                                                 |
| `config push` stops before uploading anything                                         | A `content` or `contentReference` property has no `allowedTypes`, `restrictedTypes` or `contentType`              | Every such property (array items included) needs exactly one constraint. Run `config push --dryRun` first; the CLI lists every violation                                                                               |
| A property disappeared or its type changed after a push, and content with it was lost | `config push --force`                                                                                             | Never push with `--force`. Without it the CMS rejects changes that lose data; report the rejection as a decision instead                                                                                               |
| A type you removed from code is still in the CMS                                      | `config push` never deletes                                                                                       | Deleting is a separate, confirmed step (`config delete`, or the Director in the UI); a type with content can't be deleted at all                                                                                       |
| Two projects' types collide, or a push changes another site's type                    | Type keys are instance-wide                                                                                       | Prefix every key with the project's prefix; use `--only <keys>` to push just this project's types                                                                                                                      |
| A component can't be added in Visual Builder                                          | Missing `compositionBehaviors`                                                                                    | `elementEnabled` for a block inside a column, `sectionEnabled` for a block that is a whole section. Register it with `initContentTypeRegistry` too, or the SDK fetches none of its properties                          |
| A Graph query for an item by key returns nothing                                      | The key has hyphens                                                                                               | Keys are UUIDs written as 32 hex characters without hyphens in Graph; strip them before querying                                                                                                                       |
| Publishing a second version in the same locale fails or overwrites                    | One published version per locale                                                                                  | Create a new version and publish it; the previous one becomes `previouslyPublished`, which can't be edited or republished                                                                                              |
| A draft is invisible to the head                                                      | The single key reads published content only                                                                       | Drafts need a preview token (from the preview URL, valid five minutes, sent as `Authorization: Bearer`) or an HMAC-signed request with the app key and secret                                                          |
| The preview frame in Visual Builder is blank                                          | The hostname isn't on the application, `/preview` doesn't load `communicationinjector.js`, or CSP forbids framing | Add the exact host (with port) under Settings → Applications → Hostnames; load `<CMS URL>/util/javascript/communicationinjector.js` on `/preview`; allow `frame-ancestors` and `script-src` for the CMS host           |
| Edits save but the preview doesn't refresh                                            | No `optimizely:cms:contentSaved` listener                                                                         | Use `NextPreviewComponent` (or `PreviewComponent`), which listens for the event and re-renders with the new token                                                                                                      |
| A component can't be selected in Visual Builder                                       | A custom `ComponentWrapper` without preview attributes                                                            | Spread `pa(node)` from `getPreviewUtils` onto the wrapper; a custom wrapper replaces the default one, attributes included                                                                                              |
| Display settings read as strings, or a tagged variant never renders                   | Graph returns settings as strings; `initDisplayTemplateRegistry` replaces the list on every call                  | Let the SDK convert booleans (`displaySettings?.flag` works); register every template in one call                                                                                                                      |
| Rich text renders as `[object Object]` or raw JSON                                    | SDK 3 returns rich text as JSON unless told otherwise                                                             | Render it with the SDK's `RichText` component, or set `fragment.richTextFormat`                                                                                                                                        |
| A published page never appears on the delivery host                                   | Graph not indexed yet, or the application has no route for it                                                     | Check the item in Graph (`_metadata.url.default`), then the application's start page and the item's container chain; run "Optimizely Graph Full Synchronization" under Settings → Scheduled jobs only as a last resort |
| An item exceeds Graph's limit and stops indexing                                      | Items over 29 MB                                                                                                  | Split large compositions; keep media as assets, not inline                                                                                                                                                             |
| A newly created item has no display templates applied                                 | Created through the API before August 2026 fixes, or no default template exists                                   | Mark one template per target `isDefault: true`; read the composition back and set `displayTemplateKey` where missing                                                                                                   |
| The CLI logs in to the wrong place                                                    | `--host` or `OPTIMIZELY_CMS_API_URL` set to an instance URL                                                       | Leave the API URL as the gateway; an instance URL makes the CLI call `<url>/_cms/v1`, which only the gateway form supports for keys created in the UI                                                                  |
