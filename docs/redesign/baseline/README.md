# Baseline screenshots (before the redesign)

The Control Center as it stood at `65f137b` (production branch `claude/sharp-pascal-3u2qg0`),
captured against the in-memory simulator (`SIM_PROJECTS=2 SIM_SPEED=5`, project `prj-ansell`).
They are the visual "before" for the design and UI refactor: every surface, desktop at 1440×900
(light), a dark-mode sample, and a phone sample (iPhone 14).

| Prefix     | Viewport                 | Pages                                                               |
| ---------- | ------------------------ | ------------------------------------------------------------------- |
| `desktop-` | 1440×900, light          | Dashboard, New project, 6 Manage pages, 9 project surfaces          |
| `dark-`    | 1440×900, dark           | Dashboard, Mission Control, Plan, Workbench                         |
| `phone-`   | iPhone 14 (390×844 @3x)  | Dashboard, Mission Control, Team, Plan, Needs you                   |

Simulated data moves (clocks, "just now", progress), so expect small differences on a re-capture.
