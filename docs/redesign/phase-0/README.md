# Phase 0: foundations — done

The Cypher refactor's first phase, from [the handoff](../cypher-handoff/CLAUDE.md) (plan of record:
[PLAN.md](../cypher-handoff/PLAN.md)). The old Control Center now runs inside the new Cypher shell, with
the Dial live on every screen that has two faces. Screenshots of every page in both modes and on a phone
are in this folder (`bliss-*`, `everything-*`, `phone-*`). They were captured against the simulator
(`SIM_PROJECTS=2`) at 1440×900.

## Calls made where the handoff was silent

1. **Manage pages are Everything-only.** These are Connections, Playbooks, Rules, Knowledge, Diagnostics and Global settings. The plan names only Settings and New project as one-faced. These admin pages have no Bliss face to show either.
2. **The bridge.** Old surfaces still read `prototype.css` and `app.css`. `theme/bridge.css` points every old variable (`--web-*`, `--icreon-*`, `--neutral-*`, status colors) at a Cypher token. As a result, old surfaces already show Cypher's ground, ink, lines and Plus Jakarta Sans.
   - The old blue accent becomes `ink`, because blue means Engineering. Old link buttons get a quiet `mist` underline to stay recognisable.
   - The old success background becomes `mist-2`, because green is never a background.
   - The bridge is deleted with the old stylesheet in phase 5.
3. **One theme.** The root stays `data-theme="light"`, and the old light/dark toggles are gone from the palette and the phone's More sheet. The sidebar toggle went with the old sidebar.
4. **The old dock lives in the Cypher sheet until phase 2.** The sheet's open state is the old `layout.dockOpen`, so ⌘/Ctrl /, Esc and the phone's bottom bar keep working.
5. **The old phone bottom bar stays until phase 5.** In Bliss its Cypher button becomes "Yours", because Bliss has no chat.
6. **Presentation mode still works**, with an Exit button in the Bliss header. The plan folds it into Bliss later.
7. **The Floor** now reads Cypher token names in `readTheme()`, with no hex fallbacks. This moves the Content hue from green to teal, as §5 says.
8. **Reference-board values with no token:**

   | Board value                        | Used instead                     |
   | ---------------------------------- | -------------------------------- |
   | Link color `#4a32b8`               | `ink`                            |
   | Presence pill `#fdeae6`            | `coral-tint`                     |
   | The sidebar wordmark's 24px/800    | `type-heading` at weight 800     |

   Design should either add tokens for these or confirm the substitutes.
9. **Portfolio-level sections.** §8 lists Dashboard, Needs you, Projects, Team, Workbench, Activity and Scorecard at portfolio level. Only the Dashboard exists as a surface today, so the shell shows Dashboard plus the Manage pages until the portfolio surfaces are built.
10. **Literal values left in the shell CSS:** 1px hairlines and the 640px phone breakpoint. The breakpoint matches the old bottom bar's.
