# Marks

The eye in its three states and the wordmark. These four files are the only source of the mark; the application inlines them as React components generated from these SVGs and never redraws them.

- `eye-resting.svg`: ink disc, closed lid. Nothing needs the Director.
- `eye-watching.svg`: ink disc, open eye. Agents are working.
- `eye-needs-a-word.svg`: coral disc, open eye with an ink pupil. A decision is the Director's.
- `wordmark.svg`: the resting eye beside the word *cypher*, lowercase, Plus Jakarta Sans 800, tracked tight. Use it on ink by inverting the disc to white and the word to white.

Minimum size 20px for the eye, 120px wide for the wordmark. Clear space around either is the eye's radius. The wordmark's text renders in Plus Jakarta Sans where the font is loaded; for a placement without the font, export it to paths first.
